Where the predictors of crime actually change across Chicago

A citywide regression gives one number: "more of X predicts more of Y." Geographically Weighted Regression (GWR) instead fits a separate local model at every location, revealing where each real, physical predictor of crime is strong, weak, or reversed — something a single citywide number erases entirely. Built on real 2023–2025 Chicago data (777 census tracts), replicating the methodology of Cai (2025), PLOS One.

Local model fit and coefficients, by tract

Pick a crime type and a layer. "Local R²" shows how well the four predictors explain that crime type in each part of the city. Each predictor's coefficient map shows where more of that predictor is associated with more crime (green) versus less (red) — the relationship's local direction and strength, not just whether it matters citywide.

Spatial clustering (Moran's I)

All three crime types cluster spatially, not randomly — confirming GWR is the right tool here, not an ordinary citywide regression.
