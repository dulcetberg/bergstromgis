Who's Covering Which Camp

A working demo built for Aid Evaluator, using real, public data: which organizations are active in each Rohingya refugee camp in Cox's Bazar, Bangladesh, in which sectors, and how thin that coverage actually is camp by camp. Not mock data, not a mockup, this is a real "Who does What Where" (3W) coordination dataset, the same kind of tool the UN's own humanitarian coordination office uses in real crisis response, mapped for the first time at the camp level for a system like this one.

Thin sector coverage

"Thin" means 2 or fewer organizations cover that entire sector in that camp, even though the sector is nominally present. Shelter-CCCM is thin in nearly every single camp, so on its own it doesn't distinguish anything, every camp has that gap. This toggle instead highlights the 12 of 33 camps where 3 or more sectors are thin at once, a real, meaningfully worse pattern than the citywide norm.

Partner, sector, and donor data: Inter Sector Coordination Group (ISCG), 3W Influx, Cox's Bazar, 2024, via the UN's Humanitarian Data Exchange (HDX), public domain. Camp boundaries: HDX camp outlines, April 2023. 33 camps, 17,187 real logged activities, 316 real donors.
